So verbinden sich Geräte

Am Gerät unter System → Cloud / MQTT einschalten und als Server die Adresse dieses Rechners mit Port 1883 eintragen (z. B. 192.168.0.50:1883), dazu Benutzer und Passwort aus der .env. Shelly Plus/Pro (Gen2/Gen3) gehen genauso: Einstellungen → MQTT, „RPC status notifications“ und „Generic status update“ einschalten.

Geräte erscheinen automatisch, sobald sie sich verbinden. Der Energieverlauf wird aus dem Zählerstand der Geräte berechnet.
