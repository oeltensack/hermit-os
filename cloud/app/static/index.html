Fernzugang-Portal

PHP-Seite auf einem Webhosting (Ordner portal/ im Repo). Die Cloud meldet sich dort von sich aus per HTTPS, holt Schaltbefehle ab und überträgt Zustand und Meldungen – kein offener Port nötig.

Shelly Gen2+ mit Original-Firmware anbinden

Gen2/Gen3/Gen4 können Shelly Cloud und MQTT gleichzeitig: Die Pagurus Cloud trägt sich am Gerät als MQTT-Server ein, App und Shelly Cloud laufen weiter. Danach startet das Gerät kurz neu (Relais bleiben in ihrem Zustand). Ein Gerät kann nur einen MQTT-Server haben.

Gen1-Fühler (Door/Window 2, H&T) mit Original-Firmware: vorher den Taster am Gerät kurz drücken, damit er wach ist und gefunden wird. Übernommen werden Temperatur, Helligkeit bzw. Feuchte und Batterie. Bei Gen1 schaltet MQTT die Shelly Cloud ab.
